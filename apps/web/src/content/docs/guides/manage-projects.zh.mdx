# 管理项目

项目组织您的工作、Worker 和团队协作。

## 创建项目

1. 点击仪表板上的**"新建项目"**
2. 填写项目表单：

| 字段 | 必填 | 描述 |
|-------|----------|-------------|
| **名称** | 是 | 项目标识符 |
| **仓库 URL** | 是 | Git 远程（例如 `https://github.com/org/repo`） |
| **描述** | 否 | 项目用途 |
| **默认分支** | 否 | Worktree 的基础分支（默认：main） |

3. 点击**"创建"**

## 项目仪表板

每个项目都有一个仪表板，显示：

- **看板** - 任务工作流可视化
- **最近任务** - 最新活动
- **Worker 状态** - 已连接的 Worker 及其状态
- **团队成员** - 协作者

## 项目设置

导航到 **项目** → **设置** 进行配置：

### 常规设置

| 设置 | 描述 |
|---------|-------------|
| 项目名称 | 显示名称 |
| 描述 | 项目描述 |
| 仓库 | Git 远程 URL |

### 执行设置

| 设置 | 描述 |
|---------|-------------|
| 自动清理 | 任务完成后自动移除 worktree |
| 需要审批 | 任务完成前需要人工审核 |
| 最大并发任务 | 每个 Worker 的并行任务限制 |

### 通知设置

| 设置 | 描述 |
|---------|-------------|
| 任务完成 | 任务完成执行时通知 |
| 需要审核 | 任务进入审核时通知 |
| Worker 离线 | Worker 断开连接时通知 |

## 管理团队成员

1. 导航到 **项目** → **团队**
2. 点击**"邀请成员"**
3. 输入团队成员的邮箱
4. 选择他们的角色：

| 角色 | 权限 |
|------|-------------|
| **所有者** | 完全项目访问，可以删除项目 |
| **管理员** | 管理设置、Worker 和团队 |
| **成员** | 创建、编辑和审核任务 |
| **查看者** | 对项目的只读访问 |

## 删除项目

删除项目：

1. 进入 **项目** → **设置**
2. 滚动到底部
3. 点击**"删除项目"**
4. 使用项目名称确认

> **警告**：这将删除所有任务、Worker 和历史记录。此操作无法撤消。
