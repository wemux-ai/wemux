# 创建任务

本指南引导您创建一个将由 Worker 执行的任务。

## 第 1 步：导航到您的项目

1. 登录 Wemux `http://app.wemux.localtest.me:15173`
2. 从仪表板选择您的项目
3. 点击 **看板** 选项卡查看任务看板

## 第 2 步：创建新任务

1. 点击右上角的 **"新建任务"** 按钮
2. 任务创建对话框将打开

## 第 3 步：填写任务详情

### 基本信息

| 字段 | 必填 | 描述 |
|-------|----------|-------------|
| **标题** | 是 | 简要描述（例如："修复登录 bug"） |
| **描述** | 是 | 自然语言需求 |
| **验收标准** | 否 | 任务完成的条件 |

### 示例描述

```markdown
## 需求
修复用户非活跃 30 分钟时的登录超时问题。

## 详情
- 活跃使用期间会话不应过期
- 30 分钟非活跃后，重定向到登录页
- 显示"会话已过期"消息

## 上下文
此 bug 在 #bug-reports 频道报告。
```

## 第 4 步：选择执行模式

| 模式 | 使用时机 |
|------|-------------|
| **执行任务** | 准备立即运行 |
| **新需求** | 添加到待办而不执行 |

## 第 5 步：选择 Worker

| 选项 | 描述 |
|--------|-------------|
| **自动选择** | 系统选择最佳可用 Worker |
| **指定执行器** | 选择特定的已配对 Worker |

## 第 6 步：创建任务

点击**"创建"**提交。

- 对于**执行任务**：任务进入队列并分派到 Worker
- 对于**新需求**：任务出现在待办列

## 监控您的任务

创建后，您可以：

- 在看板中跟踪状态
- 点击任务卡片打开详情抽屉
- 查看实时执行日志
- 完成后查看 AI 生成的审核备注
