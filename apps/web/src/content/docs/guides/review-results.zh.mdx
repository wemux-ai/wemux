# 审核结果

任务完成后，您需要在接受或重试之前审核输出。

## 任务完成流程

执行完成后：

1. 任务移动到看板的**审核**列
2. 您收到通知
3. 自动生成审核备注
4. 分支和产物已准备好检查

## 打开审核

1. 点击**审核**列中的任务卡片
2. 任务详情抽屉打开

## 审核内容

### 执行日志

查看 Worker 的完整终端输出：

- AI Agent 执行的命令
- 编译器输出和错误
- 测试结果
- 任何警告或问题

### 分支详情

| 项目 | 描述 |
|------|-------------|
| **分支名称** | 为此任务创建的 Git 分支 |
| **提交** | 执行期间的所有提交 |
| **变更文件** | 修改的文件列表 |
| **添加/删除行** | 变更统计 |

### 产物

下载生成的产物：

- 构建的二进制文件或包
- 测试报告
- 截图
- 生成的文档

### 审核备注

AI 生成的摘要，包括：

- 完成的工作
- 做出的关键变更
- 遇到的问题
- 建议

## 审核操作

| 操作 | 使用时机 |
|--------|-------------|
| **批准** | 任务满足验收标准，可以合并 |
| **请求更改** | 任务不完整或需要修改 |
| **重试** | 使用相同或更新的指令重新执行任务 |
| **接管** | 停止任务并手动处理 |
| **取消** | 在不完成的情况下放弃任务 |

## 批准任务

1. 审核所有输出部分
2. 验证验收标准是否满足
3. 点击**"批准"**
4. 可选择添加评论
5. 任务移动到**完成**列

## 请求更改

1. 点击**"请求更改"**
2. 添加针对 AI 的具体反馈
3. 点击**"发送"**
4. 任务返回**进行中**
5. Worker 领取反馈并重试

## 合并分支

批准后：

1. 点击**"打开分支"**在您的 Git 提供商处查看
2. 创建拉取请求
3. 按常规审核和合并
4. Worktree 自动清理
