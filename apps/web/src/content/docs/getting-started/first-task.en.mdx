# Create Your First Task

This guide shows you how to create and execute a coding task using wemux.

## Creating a Task

1. **Navigate to the Kanban board** - Go to the project you want to work on
2. **Click "New Task"** - This opens the task creation dialog
3. **Choose task mode**:
   - **Execute Task** - Immediately dispatch to a worker
   - **New Requirement** - Add to backlog without execution

4. **Fill in task details**:
   - **Title** - Brief description of the task
   - **Description** - Natural language requirements
   - **Acceptance Criteria** - What defines task completion

5. **Select execution options**:
   - **Auto-select** - System chooses the best available worker
   - **Specify Executor** - Choose a specific worker machine

6. **Click "Create"** - The task will be dispatched to the worker

## Monitoring Execution

Once a task is created:

- **Task Status** - Track progress in the Kanban board
- **Execution Logs** - View real-time logs in the task detail drawer
- **Auto Review** - See automated评审 summary after completion

## Task Lifecycle

```
Backlog → In Progress → Review → Done
         (or cancelled)
```
