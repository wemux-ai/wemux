# 了解工作区

Wemux 中的工作区实现人类与 AI Agent 之间的实时协作。

## 什么是工作区？

工作区是一个**共享编码环境**，其中：

- 团队成员可以协作处理任务
- AI Agent 在隔离的 worktree 中执行代码
- 变更通过分支和提交进行跟踪

## 核心概念

### 工作区会话

每个工作区可以有多个**会话** - 跟踪以下内容的个人编码会话：

- 分支名称和提交历史
- 执行日志
- Agent 活动

### Worktree 隔离

Wemux 使用 Git worktree 为每个任务创建隔离的分支，确保：

- **无冲突** - 每个任务在独立分支上工作
- **干净状态** - 每个任务全新的环境
- **易于清理** - 任务完成后自动清理 worktree

## 协作流程

1. 在工作区中创建任务
2. Worker 领取任务并创建 worktree
3. AI Agent 执行编码任务
4. 变更提交到专用分支
5. 您审核并合并变更
