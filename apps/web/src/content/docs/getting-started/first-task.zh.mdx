# 创建您的第一个任务

本指南展示如何使用 Wemux 创建和执行编程任务。

## 创建任务

1. **导航到看板** - 进入您想要工作的项目
2. **点击"新建任务"** - 打开任务创建对话框
3. **选择任务模式**：
   - **执行任务** - 立即分派到 Worker
   - **新需求** - 添加到待办而不执行

4. **填写任务详情**：
   - **标题** - 任务简要描述
   - **描述** - 自然语言需求
   - **验收标准** - 定义任务完成的条件

5. **选择执行选项**：
   - **自动选择** - 系统选择最佳可用 Worker
   - **指定执行器** - 选择特定的 Worker 机器

6. **点击"创建"** - 任务将分派到 Worker

## 监控执行

任务创建后：

- **任务状态** - 在看板中跟踪进度
- **执行日志** - 在任务详情抽屉中查看实时日志
- **自动审核** - 完成后查看自动生成的审核摘要

## 任务生命周期

```
待办 → 进行中 → 审核 → 完成
        （或已取消）
```
