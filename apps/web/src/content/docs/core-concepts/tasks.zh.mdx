# 任务

任务是 Wemux 中的基本工作单元。任务表示分派给 Worker 执行编码作业。

## 任务属性

| 属性 | 描述 |
|----------|-------------|
| 标题 | 工作的简要描述 |
| 描述 | 自然语言需求和上下文 |
| 验收标准 | 定义任务完成的条件 |
| 状态 | 工作流中的当前位置 |
| 分配的 Worker | 处理任务的执行器机器 |
| 优先级 | 相对重要性（影响队列排序） |

## 任务模式

创建任务时，您选择其执行模式：

### 执行任务
立即分派到可用的 Worker。任务进入执行队列并在 Worker 配对后开始。

### 新需求
添加到待办而不立即执行。用于计划和优先级排序。

## 任务状态流程

```
待办 → 进行中 → 审核 → 完成
          ↓
        已取消
```

| 状态 | 含义 |
|--------|---------|
| **待办** | 排队等待执行 |
| **进行中** | Worker 正在积极执行 |
| **审核** | 执行完成，等待人工审核 |
| **完成** | 已批准并关闭 |
| **已取消** | 任务终止而未完成 |

## 任务执行

当任务执行时，Wemux：

1. 在分配的 Worker 上创建 Git worktree
2. 将仓库克隆到 worktree
3. 为任务创建专用分支
4. 使用任务指令运行 AI Agent
5. 提交结果并报告
