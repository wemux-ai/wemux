# 项目

项目是 Wemux 中的顶级组织单元。它代表您的团队工作的代码库或仓库。

## 什么是项目？

项目包含：

- **看板** - 可视化任务管理的阶段
- **任务** - 具有执行跟踪的个人工作项
- **Worker** - 具有能力配置的配对执行器机器
- **团队成员** - 可以审核和批准工作的协作者

## 创建项目

1. 导航到主仪表板
2. 点击**"新建项目"**
3. 填写项目详情：
   - **名称** - 项目标识符
   - **仓库 URL** - 用于克隆和分支的 Git 仓库
   - **描述** - 项目用途
4. 点击**"创建"**设置项目

## 项目设置

在项目内，您可以配置：

| 设置 | 描述 |
|---------|-------------|
| 仓库 | Git 远程 URL |
| 默认分支 | Worker 创建 worktree 的分支 |
| 自动清理 | 任务完成后自动移除 worktree |
| 需要审批 | 任务完成前需要人工审核 |
