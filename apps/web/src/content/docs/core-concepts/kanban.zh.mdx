# 看板

看板提供可视化界面来跟踪任务的生命周期。

## 看板阶段

| 阶段 | 描述 |
|-------|-------------|
| **待办** | 排队的任务 |
| **进行中** | 当前正在处理的任务 |
| **审核** | 已完成等待批准的任务 |
| **完成** | 已批准并归档的任务 |

## 使用看板

### 移动任务

在列之间拖动任务以更新其状态。系统验证转换：

- 待办 → 进行中：需要分配 Worker
- 进行中 → 审核：需要执行完成
- 审核 → 完成：需要人工批准

### 筛选

按以下方式筛选看板：

- **Worker** - 显示分配给特定 Worker 的任务
- **优先级** - 高亮显示高优先级项目
- **日期范围** - 关注近期或即将到来的工作
- **搜索** - 按标题或描述查找任务

### 任务卡片

每个卡片显示：

- 任务标题和简要描述
- 当前状态指示器
- 分配的 Worker 头像
- 优先级徽章
- 执行时间（进行中时）

## 看板视图

### 我的任务

显示分配给您 Worker 的任务，以便快速监督。

### 所有任务

跨所有阶段的所有任务的完整项目视图。

### 审核队列

专门查看等待人工审核的任务。
