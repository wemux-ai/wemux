# Welcome to Wemux

Wemux is an AI coding delivery platform that orchestrates work across real repositories, workers, branches, logs, and review flows.

## What is Wemux?

Wemux provides a **worker-first** architecture where:

- **`server`** - Control plane API, scheduling, state aggregation
- **`worker`** - The only code execution entry point
- **`web`** - Unified access to the control plane

### Key Features

- **Project Management** - Create, edit, and delete projects
- **Kanban View** - Track tasks through stages: Backlog / In Progress / Review / Done
- **Task Management** - Create tasks with natural language, view status history, execution logs
- **Main Agent Orchestration** - Requirement understanding, worker routing, agent selection
- **ACP Adapter Layer** - View OpenCode status, heartbeat, capability profiles
- **Execution Center** - Current executing tasks, pending queue, remote execution chain observation
