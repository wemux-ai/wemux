# 欢迎使用 Wemux

Wemux 是一个 AI 编程交付平台，协调真实仓库、Worker、分支、日志和审核流程中的工作。

## 快速链接

- [安装指南](/docs/getting-started/installation) - 设置您的第一个 Wemux Worker
- [创建第一个任务](/docs/getting-started/first-task) - 学习任务创建的基础知识
- [了解工作区](/docs/getting-started/workspaces) - 与您的团队协作

## 什么是 Wemux？

Wemux 提供 **Worker-first** 架构：

- **`server`** - 控制面 API、调度、状态聚合
- **`worker`** - 唯一的代码执行入口
- **`web`** - 统一的控制面访问

### 核心功能

- **项目管理** - 创建、编辑和删除项目
- **看板视图** - 通过阶段跟踪任务：待办 / 进行中 / 审核 / 完成
- **任务管理** - 使用自然语言创建任务，查看状态历史、执行日志
- **主 Agent 编排** - 需求理解、Worker 路由、Agent 选择
- **ACP 适配层** - 查看 OpenCode 状态、心跳、能力配置
- **执行中心** - 当前执行的任务、待处理队列、远程执行链观察
