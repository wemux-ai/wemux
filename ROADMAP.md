# Roadmap

Wemux maintains a maintainer-owned roadmap. Community reactions and
comments inform prioritization but do not constitute a binding vote —
see [COMMUNITY-GOVERNANCE.md](docs/COMMUNITY-GOVERNANCE.md).

## Where we are

The community edition is self-hostable today: control plane, worker,
web app, desktop/mobile clients and the meeting runtime are all in this
repository under the Apache-2.0 license.

## Next

- Broader agent ecosystem integrations
- Continued reliability work across control plane and executor routing
- Documentation and onboarding improvements

Maintainer-led plan updates are posted in GitHub Discussions under a
`[roadmap]` title prefix and linked here.
