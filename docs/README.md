# Wemux Public Documentation

This directory contains documentation intended for community users and
contributors: local development, self-hosting, public architecture, testing,
telemetry, and licensing.

Product strategy, launch plans, marketing operations, internal research,
historical implementation plans, hosted-production operations, and restricted
test reports are maintained separately and must not be added here.

Start with:

- [`../README.md`](../README.md) for installation and product overview.
- [`SELF-HOSTING.md`](SELF-HOSTING.md) for Railway and other deployments.
- [`wiki/07-local-development.md`](wiki/07-local-development.md) for local development.
- [`TELEMETRY.md`](TELEMETRY.md) for community telemetry behavior.
- [`COMMUNITY-GOVERNANCE.md`](COMMUNITY-GOVERNANCE.md) for GitHub Issues and Discussions channel rules.
